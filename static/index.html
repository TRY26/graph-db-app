CognoDB Connectivity Error

The application was unable to establish a secure Bolt connection to your CognoDB instance.

Resolution Steps:

  1. Go to console.cognodb.com and sign up for a free instance.
  2. Save your connection details (URI and Password).
  3. Create a file named .env in the project root: 
    COGNODB_URI=bolt+s://<your-id>.databases.cognodb.cloud
COGNODB_PASSWORD=<your-password>
  4. Restart this server by running python3 app.py in the terminal.
Error Message Log:

No database credentials found in environment.
